# Brand Voice

## Purpose

Set a consistent written voice for public and operational communication.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Voice

Write as a capable professional: direct, calm, plain-language, and respectful. Use short sentences for next steps and explain ownership precisely.

## Tone by moment

| Moment | Tone |
| --- | --- |
| Scheduling | Clear and helpful |
| Payment | Reassuring and factual |
| Provider handoff | Precise; name the provider-hosted session |
| Problem or delay | Calm, honest, action-oriented |
| Marketing | Confident, never exaggerated |

## Guardrails

Do not imply that Avenseal itself performs identity verification or hosts the remote notarization session. Avoid legal conclusions and unsupported availability, speed, automation, or compliance claims.
