# Color Palette

## Purpose

Describe the current visual color direction without inventing unapproved token values.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Current working standard

- **Deep navy:** primary grounding color for navigation, headings, and high-trust structure.
- **Emerald:** restrained action and positive-status accent.
- **Mist/light neutral:** quiet page and card backgrounds.
- **Border neutrals:** define structure before using elevation.

Exact HEX, RGB, semantic token names, and contrast specifications are **To Be Finalized** from the implemented design tokens or approved brand assets.

## Usage

Use color sparingly and pair it with text, iconography, or structure. Preserve existing focus styling and verify contrast in the implementation.
