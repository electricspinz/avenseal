# Copywriting Guide

## Purpose

Help writers produce concise, truthful Avenseal copy.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Formula

State the customer outcome, explain the next action, and name ownership correctly. Prefer “Schedule your appointment” over vague urgency.

## Approved language

Use “Florida Remote Online Notary,” “commissioned Florida notary,” and “provider-hosted remote notarization session” where context requires precision.

## Avoid

Avoid urgency and absolutes: instant, same-day, 24/7, guaranteed, fastest, fully automated, and unqualified compliance claims. Do not state that Avenseal itself conducts identity verification or the live remote session.
