# Logo Guidelines

## Purpose

Protect the Avenseal mark while final asset files are being approved.

**Status:** To Be Finalized
**Last Updated:** 2026-08-08

## Current working rules

Use only approved Avenseal horizontal or mark variants. Maintain clear space, preserve proportions, and select navy or white treatment for sufficient contrast. Do not recolor, stretch, crop, outline, animate excessively, or place the mark on busy imagery.

## Availability

Final files and file paths are not confirmed in this repository. See [Brand Assets](./Brand-Assets.md) before creating campaign or listing materials.
