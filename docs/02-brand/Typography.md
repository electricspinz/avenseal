# Typography

## Purpose

Set readability-first typographic guidance without claiming an unapproved font family.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Guidance

Use the implemented site type system and maintain clear H1–H3 hierarchy, comfortable body line length, restrained weight changes, and sentence-case interface labels. Do not introduce a new font family without an approved asset or design decision.

## Accessibility

Keep text readable at browser zoom, do not use tiny all-caps body copy, and do not rely on low-contrast muted text for essential instructions.

## To Be Finalized

Final font-family names, font files, scale, and fallback stack should be recorded from approved brand assets or the production design system.
