# Public Design System

## Purpose

Capture the existing public visual language at a safe, implementation-neutral level.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Current direction

Avenseal uses a navy, emerald, and mist/light-neutral direction with generous whitespace, border-led cards, restrained elevation, and a calm legal-tech character. The repository uses Next.js, React, Tailwind CSS, and shared components; see [Architecture Overview](../09-technology/Architecture-Overview.md).

## Component expectations

Buttons communicate hierarchy, cards group related choices, status messages use text as well as color, and forms retain labels, focus states, and clear validation. Reuse the implemented visual patterns rather than introducing one-off styles.

## To Be Finalized

Exact public token values, type scale, component inventory, and approved icon/illustration library.
