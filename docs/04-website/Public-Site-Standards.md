# Public Site Standards

## Purpose

Set launch-safe content, accessibility, and quality expectations for public pages.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Content

Use factual, customer-centered copy. State that identity verification and the remote notarization session occur through the online notarization provider and that a commissioned notary completes the notarization. Avoid unsupported speed, availability, automation, security, certification, or compliance claims.

## Accessibility and responsive quality

Maintain one clear H1, logical heading order, labeled controls, meaningful alternatives for non-decorative images, keyboard access, visible focus, and mobile-readable spacing. Decorative artwork should be hidden from assistive technology.

## SEO baseline

Every indexable public page needs a unique title, description, canonical URL, Open Graph title/description/URL, and truthful page content. See [Metadata Standards](../05-seo/Metadata-Standards.md).
