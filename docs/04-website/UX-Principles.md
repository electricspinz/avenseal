# UX Principles

## Purpose

Set customer-experience principles for the public site and appointment journey.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Principles

1. **Make the next step obvious.** One primary action per decision point.
2. **Explain ownership accurately.** Avenseal supports discovery, scheduling, payment, communications, and workspace access; the provider hosts identity verification and the remote session.
3. **Reduce uncertainty.** Explain what happens before, during, and after an appointment without making unsupported promises.
4. **Respect attention.** Use concise copy, visible status, and predictable forms.
5. **Design inclusively.** Preserve keyboard access, readable contrast, clear labels, and useful errors.

## Avoid

Avoid false urgency, decorative complexity, hidden requirements, and page copy that implies guaranteed notarization outcomes.
