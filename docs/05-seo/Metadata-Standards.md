# Metadata Standards

## Purpose

Define truthful metadata requirements for indexable public pages.

**Status:** Current working standard
**Last Updated:** 2026-08-08

## Required fields

Each indexable public page should provide a unique title, concise description, canonical URL, Open Graph title, Open Graph description, and Open Graph URL. The public-site canonical base is intended to be https://avenseal.com; production domain verification remains operational work.

## Content rules

Metadata must match the visible H1 and page content. Do not place phone numbers, sensitive workflow data, promises of outcomes, or unsupported claims in titles or descriptions.

## To Be Finalized

Approved title patterns, social image dimensions, Search Console validation, and final noindex decisions.
