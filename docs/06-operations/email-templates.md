# Approved Email Template Principles

Use the repository’s communications templates and customer-safe link workflows. Do not paste access tokens, BlueNotary URLs, document contents, payment processor details, or security incident facts into manual email.

| Scenario | Required content |
| --- | --- |
| Booking received | Safe confirmation and next step; no promise of notarization. |
| Payment needed | Disclosed fee and secure Client Workspace action. |
| Session available | Explain that BlueNotary hosts the online session; use the authorized handoff path. |
| Reschedule/no-show | Approved policy-based next step. |
| Support response | Minimum necessary facts and secure workflow link. |

Final customer-facing wording must follow the [content style guide](../01-design-system/content-style.md) and attorney-approved legal copy.
