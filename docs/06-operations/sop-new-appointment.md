# SOP: New Appointment

1. Confirm the request is in Avenseal and belongs to the correct organization.
2. Review only operational booking facts; route notarial eligibility questions to the commissioned notary.
3. Confirm disclosed fee and payment status. Do not alter pricing from customer input.
4. Send or regenerate Client Workspace access only through approved admin actions.
5. Record safe operational notes/audit evidence; never copy access tokens, documents, or session links into notes.
6. If a BlueNotary session is manually supplied, confirm it is trusted staff-provided before customer exposure.
