# SOP: Security Incident

1. Stop the affected workflow if safe; preserve quarantine and queue evidence.
2. Do not copy sensitive data into tickets, chat, or unapproved logs.
3. Notify the designated security/incident owner immediately.
4. Record time, affected system, safe category, containment action, and owner.
5. Rotate or revoke credentials only through approved operations procedures.
6. Escalate legal-hold, privacy, vendor, and customer-notice decisions to counsel and leadership.

Do not activate quarantined documents, bypass tenant checks, or make customer-notice/legal determinations without authorization.
